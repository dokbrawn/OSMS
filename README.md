# Основы систем мобильной связи (ОСМС)

Практические работы по курсу «Основы систем мобильной связи» (СибГУТИ, направление 09.03.01).
Код на MATLAB: обработка сигналов (дискретизация, спектр, квантование) и расчёты по сетям мобильной связи.
Алгоритмы пишутся вручную, без готовых «чёрных ящиков» вроде `fft`.

**Автор:** Анисимов Тимур Юрьевич · [@dokbrawn](https://github.com/dokbrawn)
**Статус:** практика 1 выполнена, остальные — по мере прохождения курса.

![Дискретизация сигнала на частоте 10 Гц и 40 Гц](practice-1/assets/sampling.svg)

*Практика 1: сигнал `y(t) = 2·sin(2π·5·t + π/6)`, дискретизация на `fs = 10 Гц`
(минимум по теореме Котельникова) и на `fs = 40 Гц`. При `fs = 10 Гц` все отсчёты равны ±1,
хотя амплитуда сигнала 2 — на границе теоремы результат зависит от фазы.*

## Практика 1: что сделано

- **Дискретизация и восстановление.** Непрерывный сигнал варианта, дискретизация на минимальной частоте и на частоте ×4, восстановление линейной интерполяцией.
- **Спектр.** Амплитудный спектр аудиофайла по определению ДПФ (через `cos` и `sin`), сравнение с сигналом, прореженным в 20 раз.
- **Квантование.** Округление отсчётов до уровней АЦП при разрядности 3–6 бит, оценка ошибки.
- **Дополнительно.** Синтез мелодии *He's a Pirate* и её спектр.

Ручное ДПФ, которое используется в работе:

```matlab
function [Amp, fa] = manual_dft(x, fs)
    N   = length(x);
    k   = (0:floor(N/2))';
    n   = 0:N-1;
    ang = 2*pi*k*n/N;
    R   = cos(ang)*x(:);
    I   = -sin(ang)*x(:);
    Amp = sqrt(R.^2 + I.^2) * 2/N;
    fa  = k*fs/N;
end
```
