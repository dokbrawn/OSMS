# Практика 1: временная и частотная формы сигналов

Первая практика курса: дискретизация непрерывных сигналов, ручное ДПФ,
квантование и синтез мелодии. Отчёт по работе лежит рядом в `lab1.pdf`.

## Файлы

| Файл | Что внутри |
| --- | --- |
| [`lab1_part1.m`](lab1_part1.m) | дискретизация на fs = 2·fmax и ×4, восстановление линейной интерполяцией |
| [`lab1_voice.m`](lab1_voice.m) | спектр аудио по определению ДПФ (без `fft`), прореживание в 20 раз |
| [`lab1_part3.m`](lab1_part3.m) | квантование 3–6 бит, оценка ошибки MSE |
| [`lab1_melody.m`](lab1_melody.m) | синтез мелодии _He's a Pirate_ и её амплитудный спектр |
| [`lab1.pdf`](lab1.pdf) | отчёт по практической работе № 1 |

## Как запустить

Открыть нужный `.m` в MATLAB и нажать **Run**. Для `lab1_voice.m` положить
рядом с файлом `voice.wav` (музыкальная запись или речь).
